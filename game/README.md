# AI Practice

[Open in ChatGPT Sites](https://kapil-ai-weekly-practice.dreamysnipe514.chatgpt.site) · [Local app](http://127.0.0.1:8765/game/)

Run `python game/server.py` from the repository, then open [the local app](http://127.0.0.1:8765/game/). On Windows, `game/start.ps1` starts it quietly in the background.

Choose a week, then a year or **All years**. Click an answer for immediate feedback, the correct choice, and the explanation. Progress stays in this browser; restart a set or retry missed questions whenever you want.

All 530 source-question entries are represented: the 120 original 2026 MCQs, plus 410 historical recap questions with practice choices. Earlier wording is adapted where needed to make diagrams, incomplete choices, and ambiguous source keys answerable. Original screenshots and source-answer notes are available after answering. Practice option letters can differ from the screenshots.

The app works without an internet connection once these files are present. The local server listens only on `127.0.0.1`; it serves the app and question screenshots. It does not expose private build files.
